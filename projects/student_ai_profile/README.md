# Mini Project — Student AI Profile

## Goal
Build a small command-line Python program that collects student information and displays an AI-learning profile.

## Requirements
Collect:
- Name
- Age
- College
- Course
- Three AI/ML skills

Then display the information in a clean format.

## Concepts Practiced
- `input()`
- Variables
- Lists
- Dictionaries
- Functions
- Loops
- Basic validation

## Run

```bash
python main.py
```

## Extension Ideas
- Add GitHub and LinkedIn fields.
- Calculate number of skills.
- Add a simple learning-progress percentage.
- Save the profile to a JSON file.
