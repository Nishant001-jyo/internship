# 2. Real-World Applications of AI

AI is used across many industries. The technique and data depend on the problem.

## 1. Healthcare
Applications:
- Medical image analysis
- Patient-risk prediction
- Drug discovery support
- Clinical documentation assistance

AI should support qualified professionals and should not be treated as automatically correct medical advice.

## 2. Finance
Applications:
- Fraud detection
- Credit-risk analysis
- Customer-service chatbots
- Transaction anomaly detection

## 3. E-Commerce
Applications:
- Product recommendations
- Search ranking
- Demand forecasting
- Personalized experiences

## 4. Transportation
Applications:
- Route optimization
- Traffic prediction
- Driver-assistance systems
- Predictive maintenance

## 5. Education
Applications:
- Personalized learning
- Automated practice feedback
- Question generation
- Learning analytics

## 6. Cybersecurity
Applications:
- Anomaly detection
- Spam/phishing detection
- Malware analysis
- Security monitoring

## 7. Generative AI
Generative AI systems create new content such as:
- Text
- Images
- Audio
- Code

Examples:
- AI writing assistants
- Coding assistants
- Image-generation systems
- Document question-answering systems

## AI Workflow Example

For a simple image classifier:

```text
Collect Images
      ↓
Clean / Label Data
      ↓
Train Model
      ↓
Evaluate Model
      ↓
Deploy
      ↓
Give New Image
      ↓
Prediction
```

## Important AI Limitations

AI systems can:
- Make incorrect predictions.
- Learn unwanted patterns from poor data.
- Produce confident but incorrect outputs.
- Reflect bias present in data or system design.

Therefore, evaluation, testing, monitoring, privacy, and human oversight are important.
