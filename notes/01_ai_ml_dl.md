# 1. Artificial Intelligence, Machine Learning & Deep Learning

## What is Artificial Intelligence?

Artificial Intelligence (AI) is the broad field of building computer systems that can perform tasks that normally require human-like intelligence.

Examples:
- Understanding text
- Recognizing images
- Recommending products
- Translating languages
- Answering questions
- Detecting patterns
- Planning or making decisions

### Simple Example

A voice assistant receives speech, converts it into text, interprets the request, and produces a response. Different AI techniques can be involved in this pipeline.

## What is Machine Learning?

Machine Learning (ML) is a subfield of AI where systems learn patterns from data and use those patterns to make predictions or decisions.

Instead of explicitly writing every rule, we provide examples and an algorithm learns a model.

### Example

Suppose we have historical house data:

```text
Area    Bedrooms    Price
1000    2           40 lakh
1500    3           60 lakh
2000    4           80 lakh
```

An ML model can learn the relationship between features such as area and bedrooms and the target price.

## What is Deep Learning?

Deep Learning (DL) is a branch of ML that uses neural networks with multiple layers.

DL is especially useful for:
- Images
- Audio
- Natural language
- Complex pattern recognition

Examples include image classification, speech recognition, and many modern language-model systems.

## AI vs ML vs DL

```text
Artificial Intelligence
│
├── Machine Learning
│   │
│   └── Deep Learning
│
└── Other AI approaches
```

Think of them as nested concepts:

- AI = broad field
- ML = learning from data within AI
- DL = neural-network-based ML

## Common ML Learning Types

### 1. Supervised Learning
The training data contains inputs and known answers (labels).

Examples:
- Spam vs not spam
- House-price prediction
- Disease-risk classification

### 2. Unsupervised Learning
The data has no target labels. The algorithm tries to discover structure.

Examples:
- Customer segmentation
- Clustering

### 3. Reinforcement Learning
An agent learns by interacting with an environment and receiving rewards or penalties.

Examples:
- Game-playing agents
- Robot control

## Important Terms

- Data: information used by a system.
- Feature: an input variable used for prediction.
- Label/target: the value the model tries to predict.
- Model: a learned mathematical/computational representation.
- Training: learning patterns from data.
- Inference: using a trained model on new input.

## Quick Revision

AI asks: "How can a computer perform an intelligent task?"

ML asks: "How can a system learn patterns from data?"

DL asks: "How can neural networks learn complex patterns from large amounts of data?"
